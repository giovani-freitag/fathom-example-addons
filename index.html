Fathom addons

Indicators you can read, take apart and change. Each one is TypeScript that Fathom compiles in the page — no build step stands between this source and the chart.

Open the chart Write your own Source

Three ways in

  1. Paste the address. In the chart, press Write a reading, then the cloud button. Fathom lists every file and its size before it fetches a byte.
  2. Take the one file. Each release carries a .fathom.json per addon, for the open button.
  3. Copy it by hand. The source is below, whole. That is what runs.

MIT. Take these apart — an addon that teaches something these do not is welcome.
